1. ПОНЯТИЕ ВЕЛИЧИН И ДАННЫХ В ПРОГРАММИРОВАНИИ

1.1. Базовые понятия информатики, величины и данные

Раздел информатики, посвящённый алгоритмизации и программированию, изучает методы разработки программного обеспечения (ПО), а также методы программного управления устройствами и вычислительными машинами. Создание какого-либо программного продукта — это, по сути, решение некоторой задачи, в процессе чего программисту приходится иметь дело с различными величинами.

Величина — это какая-либо характеристика объекта, существенная для решения задачи (например: длина отрезка, площадь фигуры, количество символов, процентная ставка по вкладу и т. д.).

Данные — это совокупность величин, обрабатываемых при решении задачи.

1.2. Классификация данных в рамках решаемой задачи

  • 1. Исходные данные — совокупность величин, значениями которых пользователь может варьировать в ходе выполнения программы (приложения).
  • 2. Выходные данные — совокупность величин, содержащих результат выполнения программы.
  • 3. Промежуточные данные — совокупность величин, связывающих исходные и выходные данные.
Логическая структура определения понятия (Понятие = Род + Видовое отличие)
На примере понятия «Исходные данные»:
1) Родовой признак: «совокупность величин».
2) Видовое отличие: наличие механизма варьирования (ввода) величин в ходе работы программы.
Аналогично для «Выходные данные»: родовой признак — совокупность величин; видовое отличие — содержащих результат.

1.3. Пример выделения данных при решении квадратного уравнения

Задача: решить квадратное уравнение ax² + bx + c = 0.

  • Исходные данные: a ∈ R \ {0}, b ∈ R, c ∈ R.
  • Выходные данные: x₁ ∈ R, x₂ ∈ R.
  • Промежуточные данные: дискриминант D = b² − 4ac.
  • Связь: x₁ = (−b + √D) / (2a), x₂ = (−b − √D) / (2a).

1.4. Свойства величин. Постоянные и переменные величины

  • 1. Имя (идентификатор) величины — последовательность символов алфавита языка программирования.
  • 2. Тип величины — определяет способ хранения, область допустимых значений и допустимые операции.
  • 3. Значение величины — на физическом уровне ячейка оперативной памяти, хранящая значение в виде двоичного кода.

По возможности изменения значения:

  • Постоянная величина (константа) — значение невозможно изменить в ходе выполнения программы.
  • Переменная — значение может изменяться в ходе работы программы.

2. ТИПЫ ДАННЫХ В ЯЗЫКАХ ПРОГРАММИРОВАНИЯ

2.1. Характеристики типа данных

Тип данных однозначно определяет 3 характеристики:

  1. Формат внутреннего представления величины в памяти ЭВМ.
  2. Множество допустимых значений.
  3. Множество допустимых операций.

2.2. Простые (примитивные / скалярные) типы данных

  • Целый тип (Z) — для целочисленных величин.
  • Вещественный тип (R) — для величин с дробной частью.
  • Логический (булевский) тип — False (0) / True (1).
  • Символьный тип — для отдельных символов.

3. ЭТАПЫ РЕШЕНИЯ ЗАДАЧ НА ЭВМ

3.1. Общая последовательность этапов

  1. Постановка задачи.
  2. Математическая постановка (построение математической модели).
  3. Техническое задание — ТЗ (спецификация).
  4. Выбор программного обеспечения (ПО).
  5. Проектирование тестов.
  6. Реализация (алгоритмизация, программирование, отладка и тестирование).
  7. Получение результата, его анализ и интерпретация.

3.2. Этап №1: Постановка задачи и анализ её структуры

Ключевые вопросы: Что дано? Что требуется найти? Корректно ли условие?

Задача состоит из трёх компонентов: Условие, Требование, Оператор.

  • Условие задачи — предметная область и свойства объектов (качественные и количественные).
  • Требование задачи — указание цели («найти», «проанализировать» и т.д.).
  • Оператор задачи — совокупность действий для выполнения требования.
Корректность постановки: если нет противоречий и достаточно данных — задача корректна. Иначе вводятся допущения.

Пример: «Найти площадь фигуры» — некорректно (не указан вид фигуры).
Допущение 1: фигура — прямоугольник со сторонами a и b.
Допущение 2: фигура из множества F = {прямоугольник, круг, равносторонний треугольник}.

3.3. Этап №2: Математическая постановка

Формализация условия в математическую форму: вводятся обозначения для исходных и выходных данных, устанавливается связь формулами.

3.6. Этап №5: Проектирование тестов

  • Тест — совокупность исходных данных с заранее известным результатом.
  • Цель тестов — найти как можно больше ошибок.

3 принципа: независимость составителя, опережающая разработка, повторное тестирование после правок.

Методы: «чёрный ящик» (без знания кода) и «белый ящик» (с доступом к коду).

3 правила «белого ящика»: покрытие условий, граничные случаи, недопустимые случаи.

4. АЛГОРИТМИЗАЦИЯ И МЕТОДЫ РАЗРАБОТКИ АЛГОРИТМОВ

4.1. Понятие алгоритма, команды, операторы и СКИ

Определение алгоритма (по А. П. Ершову, 1985 г.)
Алгоритм — это понятное и точное предписание (указание) исполнителю совершить последовательность действий, направленных на достижение указанной цели или на решение поставленной задачи.
  • Команда — отдельное законченное указание исполнителю.
  • Оператор — реализация команды в языке программирования.
  • СКИ — система команд исполнителя.
  • Алгоритмизация — процесс составления алгоритма.

4.2. Свойства алгоритма

  1. Дискретность — разбиение на шаги.
  2. Понятность — команды понятны исполнителю.
  3. Детерминированность — однозначность результата.
  4. Результативность — завершение за конечное число шагов.
  5. Массовость (дополнительное) — применимость к классу задач.

4.3. Способы записи алгоритмов и элементы блок-схем по ГОСТ 19.701-90

Способы: словесный, аналитический, графический (блок-схемы).

5. ПРАКТИЧЕСКАЯ РАБОТА №2

Задача 3 (линейный алгоритм): расстояние между двумя точками.

  • Модель: S = √((x₂ − x₁)² + (y₂ − y₁)²).

Задача на разветвление №1: принадлежность точки кругу.

  • Формула: x² + y² ≤ r² → «Принадлежит», иначе «Не принадлежит».

1. ПРЕДМЕТНОЕ НАЗНАЧЕНИЕ ЭВМ. ПОНЯТИЕ ИНФОРМАЦИИ, ДАННЫХ И МЕТОДОВ

1.1. Информатика и ЭВМ

Научное направление «ЭВМ и информатика» изучает информационные процессы, возникающие в объектах различной природы, и возможность их автоматизации.

Основные понятия: информационный процесс, информационная модель, алгоритм, программа, вычислительное устройство (ЭВМ).

Вклад внесли: Лейбниц, Беббидж, Буль, Тьюринг, Шеннон, Винер.

1.2. Подходы к пониманию информации в науке

  • В физике (40-е годы): мера упорядоченности, антиэнтропии (хаоса) в системе.
  • В кибернетике: всё то, что задействовано в каналах связи при управлении.
  • В математике: совокупность символов соответствующего алфавита или кодовой таблицы.
  • В естественных науках: знания об уровне развития объектов или явлений окружающего мира.
Ключевое определение: Данные — это зарегистрированные сигналы, а информация — это результат слияния данных и адекватных им методов.

1.3. Диалектическое единство данных и методов

Сигналы → регистрация → ДАННЫЕ → применение метода (считывание/обработка в ЭВМ) → ИНФОРМАЦИЯ (динамический результат).

1.4. Свойства и процессы обработки информации в ЭВМ

Свойства: объективность, полнота, достоверность, адекватность, доступность, актуальность.

Виды информационных процессов: сбор/поиск, передача, хранение, обработка, защита, представление.

  • Источники информации — элементы окружающего мира, передающие сведения.
  • Потребители (приемники) — субъект, получающий и использующий данные.

2. АРХИТЕКТУРА ЭВМ И ПОДСИСТЕМА ПАМЯТИ

2.1. Основные определения

ЭВМ — устройство или комплекс устройств для автоматической обработки информации, решения задач путём выполнения заданной программы.

Процессор (CPU) — центральное устройство, управляющее процессами и обрабатывающее данные. Включает АЛУ, УУ, регистры и кэш-память.

2.2. Иерархия подсистемы памяти ЭВМ

  1. Сверхбыстрая память: регистры процессора и кэш-память (L1, L2, L3).
  2. Оперативная память (ОЗУ / RAM): энергозависимая динамическая память для текущих программ.
  3. Постоянная память (ПЗУ / ROM): энергонезависимая память, хранящая BIOS/UEFI и POST-тесты.
  4. Внешняя память (ВЗУ): HDD, SSD, флеш-накопители и оптические диски.
